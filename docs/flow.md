# יומן חכם: זרימה והפעלה

## הזרימה
1. מעלים מסמך (PDF, תמונה, אימייל, טקסט). הקובץ נשמר ב-Storage תחת `yoman-documents/{user_id}/`.
2. Edge Function `yoman-extract` שולחת ל-Claude ומחזירה JSON. מפתח Claude נשאר בשרת.
3. מסך האישור מציג מה חולץ. אפשר לערוך, ורק "שמירה ביומן" כותבת לטבלה.
4. הלוח החודשי מציג את האירועים. לחיצה פותחת את הפרטים.
5. כל יום ב-08:00 (שעון ישראל) `yoman-reminder` שולחת ווצאפ על אירועי מחר, ורק אז מסמנת `reminder_sent`.

## סטייה מהאיפיון המקורי (מוסברת)
- `VITE_CLAUDE_API_KEY` בצד לקוח היה חושף את המפתח לכל מבקרת. הקריאה עוברת ל-Edge Function.
- `select('*, auth.users!inner(phone)')` לא עובד ב-PostgREST. מספר הווצאפ נשמר בטבלת `yoman_profiles` ונקבע בהגדרות.
- חישוב "מחר" נעשה לפי Asia/Jerusalem ולא UTC.
- אין אימוג'י בהודעת הווצאפ (כלל קבוע).

## הפעלה (חד־פעמי)
```bash
supabase link --project-ref <REF>
supabase db push
supabase secrets set ANTHROPIC_API_KEY=... TWILIO_ACCOUNT_SID=... TWILIO_AUTH_TOKEN=... TWILIO_WHATSAPP_FROM=whatsapp:+14155238886 CRON_SECRET=<אקראי>
supabase functions deploy yoman-extract yoman-test
supabase functions deploy yoman-reminder --no-verify-jwt
```
בלוח של Supabase: Authentication, Providers, Google. כתובת ההחזרה היא כתובת Vercel.

## תזמון (SQL Editor, פעם אחת)
הפונקציה בודקת את השעה בישראל ושולחת רק ב-08:00, לכן מתזמנים אותה פעמיים ב-UTC (05:00 לקיץ, 06:00 לחורף), ורק אחת מהן שולחת בפועל.
```sql
select cron.schedule('reminder-0500utc', '0 5 * * *', $$
  select net.http_post('https://<REF>.supabase.co/functions/v1/yoman-reminder', '{}'::jsonb,
    headers := '{"x-cron-secret":"<CRON_SECRET>"}'::jsonb) $$);
select cron.schedule('reminder-0600utc', '0 6 * * *', $$
  select net.http_post('https://<REF>.supabase.co/functions/v1/yoman-reminder', '{}'::jsonb,
    headers := '{"x-cron-secret":"<CRON_SECRET>"}'::jsonb) $$);
```
בדיקה ידנית בכל שעה: מוסיפים `?force=1` לכתובת.

## Vercel
משתני סביבה: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`. פריסה מ-`main`. הרישום ב-aoa_apps נעשה רק בהוראה מפורשת.

## עדכון: כניסה בקישור פרטי (במקום Google)
- הגישה לנתונים עוברת רק דרך Edge Function `yoman-api`, מוגנת במפתח אישי בכותרת `x-yoman-key`.
- בטבלה `yoman_keys` נשמר רק ה-SHA-256 של המפתח. טבלאות הנתונים נעולות ב-RLS בלי מדיניות.
- קישור פרטי: `https://yoman-gh.vercel.app/#k=המפתח`. נפתח פעם אחת בכל מכשיר, והמפתח נשמר בדפדפן.
- בהגדרות: העתקת הקישור, החלפת מפתח (המפתח הישן מפסיק לעבוד), ויציאה מהמכשיר.
- סודות בשרת: `ANTHROPIC_API_KEY` (קיים), ו-Twilio (עוד לא).

## קטגוריות בצבעי קשת
- שבעה צבעים: אדום, כתום, צהוב, ירוק, כחול, אינדיגו, סגול. ברירת מחדל: עבודה אדום, בילוי ירוק, רפואה כחול, לימודים סגול. כתום, צהוב ואינדיגו פנויים לשמות חדשים.
- שמות הקטגוריות נערכים במקרא שמתחת ללוח ("עריכת קטגוריות") ונשמרים אוטומטית (`yoman_profiles.categories`).
- לכל אירוע שדה `category` (מפתח הצבע). היום בלוח נצבע בצבע הקטגוריה של אירועיו, ויום עם כמה קטגוריות מוצג בפסים.
- בחילוץ ממסמך, Claude מציע קטגוריה מתוך השמות הקיימים, ואפשר לשנות לפני שמירה.

## תצוגות מתגלגלות ורשימת משימות
- תצוגות: יום (3 ימים), שבוע (7 ימים), חודש (5 שבועות) ו-3 חודשים (13 שבועות). בכולן "היום" נמצא בדיוק במרכז החלון. הקודם והבא מזיזים את החלון, ו"חזרה להיום" מחזיר.
- כותרות ימי השבוע גדולות, והעמודה של היום מסומנת. התצוגה האחרונה נשמרת בדפדפן.
- רשימת משימות בצד: הקלדה או הקלטה בעברית, תיבת סימון שמעבירה קו חוצה על משימה שבוצעה, הערה לכל משימה, וסינון (הכול, פתוחות, בוצעו).
- משימות נשמרות בטבלה `yoman_tasks` דרך הפונקציה `yoman-tasks`, באותו מפתח אישי.

## עדכון: לוח עם מסגרות, אייקונים והקלטה
- לחיצה כפולה על יום (או +) פותחת אירוע חדש לתאריך הזה, עם הסמל בשם. Enter שומר.
- היום במסגרת שחורה. מסגרת לכל שבוע, וקו עבה בגבול כל חודש. שישי ושבת באפור בהיר.
- חמש תצוגות: יום, שבוע, חודש, חודשיים, 3 חודשים. בכולן היום במרכז.
- אייקון לכל קטגוריה (עבודה תיק, בילוי כוס, רפואה צלב, לימודים ספר, ועוד שלושה) בתוך מסגרת היום.
- הוספה ומחיקה באייקוני + ו-X. האירוע הבא במרקר צהוב, ושורת התאריך שלו גדולה ומהבהבת.
- הקלטה ותמלול: בתיאור אירוע, בהערה ובמשימה, וגם "הקלטת אירוע" שמחלץ את הפרטים מהדיבור. שגיאות מוצגות בעברית.

## דף פתיחה: השראה להיום
- נפתח אוטומטית בפעם הראשונה בכל יום, ובכל רגע מתפריט הלוגו ("השראה להיום").
- שמונה כרטיסים מהאפליקציות האחרות בפרויקט, קבועים לכל היום: משפט העצמה ותובנת ידע (CULTURA), אימון עם תשובות (DAPAR), תרגיל (המהות), אקטואליה (RADAR), שיר (קישור ל"שיר ביום"), רעיון מזוקק (ZIKUK), מילה להרהור (FACES).
- הפונקציה `yoman-inspire` קוראת רק טבלאות תוכן, ולא טבלאות אישיות (טיפול, קבלות, לקוחות).
- שיר: אין בפרויקט טקסט של שירים, ולכן הכרטיס מקשר לאפליקציית "שיר ביום".

## שבוע מיום ראשון, שליש ושני שלישים, מסך עבודה
- השבוע מתחיל ביום ראשון בכל התצוגות. שורת היום (שבוע העוגן) תמיד השורה האמצעית: חודש 5 שורות, חודשיים 9, שלושה חודשים 13. תצוגת יום: אתמול, היום, מחר.
- פריסה: שני שלישים ליומן ושליש למשימות. בשורת משימה: הערה ו-X באייקונים בצד שמאל, כדי לפנות מקום לטקסט.
- קישורים חשובים (ברירת מחדל: מייל): ערוכים בלחיצה על העיפרון, נשמרים בשרת (`yoman_profiles.links`).
- מסך עבודה (`/work`): כותבים או אומרים בקשה, והפונקציה `yoman-work` (Claude) מכינה טיוטה לאישור: מייל (נפתח ב-Gmail עם כתובת, נושא ותוכן), אירוע, משימה, או הודעת ווצאפ. לא שולח כלום בעצמה.
- אנשי קשר (`yoman_profiles.contacts`): כתובת או טלפון שהוזנו פעם אחת נשמרים ומתמלאים לבד.
- דף פתיחה: היום, מחר (להתכונן), משימות פתוחות, בוצעו אתמול, והשראה בשורות מסודרות עם אייקון האפליקציה של כל כרטיס (תמונת השער מתיק האפליקציות).
